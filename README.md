# AI Employee

A demo AI Employee for a small store. Customers chat in Arabic, French, or English to ask about products and build an order, while the backend validates every detail and creates a real order.

**Demo only. Don't enter real personal data.**

## Tech stack

- **Next.js 16** (App Router) with **TypeScript**
- **React 19** and **Tailwind CSS**
- **PostgreSQL** hosted on **Neon**
- **Prisma** ORM — planned, not installed yet
- **Google Gemini** SDK
- **Vercel** hosting
